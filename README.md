### 🌟 The Big Picture

> **HTTP** is the **communication protocol** that enables clients and servers to talk to each other across the web.

> An **API** defines what a backend **allows** other applications to **do** - it's the contract between services.

> **REST APIs** typically use HTTP methods as their verbs:
> - 📝 **GET** - Retrieve data
> - 📤 **POST** - Create new resources
> - 🔄 **PUT** - Update entire resources
> - ✏️ **PATCH** - Partial updates
> - 🗑️ **DELETE** - Remove resources

- **HTTP Methods** are like verbs in a sentence - they give meaning to the action
- **Status Codes** are the server's mood indicators (200 = happy, 404 = lost, 500 = broken)
- **Headers** are like envelopes - they contain important metadata about the request/response
- **Cookies** are tiny pieces of data that help servers remember you
- **REST** is not a protocol but an architectural style that leverages HTTP
